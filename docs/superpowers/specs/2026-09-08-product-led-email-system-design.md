# Product-led Transactional Email System

## Direction

Jobwhisper emails should feel direct, useful, and recognizably ours without wrapping every message in decorative UI. The references point to a restrained product-email language: clear logo, strong subject headline, concise copy, one obvious action, and structure only where the content benefits from it.

## Shared frame

- Use a quiet neutral page background and a 640px white email body.
- Place the Jobwhisper wordmark inside the email with compact top spacing.
- Use Rethink Sans throughout. Headings are bold and practical; greetings return to body scale.
- Use cobalt for links, the primary button, and the verification code—not as a full-page backdrop.
- Keep one primary CTA per message.
- Use a single hairline rule to separate the footer. Footer copy is small, neutral, and link-led; social icons are removed.
- At mobile widths, preserve readable padding and make the CTA full width.

## Content patterns

- Authentication: heading, greeting, instruction, one six-digit code band, expiry, fallback action, quiet security sentence.
- Billing: outcome-led heading, concise explanation, receipt facts in simple divided rows, action, support sentence.
- Job alerts: match-count heading, short context, divided job rows with a small match percentage and direct job link, then one “View all matches” action.
- Reports: ready-state heading, session context, a prominent numeric result, a short fact list, and one report action.
- Meeting recap: meeting title and metadata, short summary, a plain divided action list, and one transcript action.

## Restraint rules

- No oversized greeting, tinted callout, accent rail, pill badge, nested dashboard card, or ornamental label.
- Rounded containers are reserved for the outer email body and code band.
- Information tables use rules and spacing rather than filled cards.
- Copy stays specific to the action or artifact being delivered.
